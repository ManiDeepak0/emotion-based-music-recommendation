# Emotion Based Music Recommendation System

## Description

An emotion-based music recommendation system that detects a person's
facial emotion using a deep learning model and recommends music based
on the detected emotion.

## Features

- Facial emotion detection
- Real-time emotion recognition
- Seven emotion categories
- Music recommendation based on detected emotion
- OpenCV-based face detection
- Deep learning-based emotion classification

## Technologies Used

- Python
- OpenCV
- TensorFlow
- Keras
- NumPy
- Imutils

## Emotions

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise
